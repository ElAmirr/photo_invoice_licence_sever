============================================
HOW TO CHANGE THE DATABASE - COMPLETE GUIDE
============================================

STEP 1 - Create new database on Render
---------------------------------------
- Go to Render Dashboard > New > PostgreSQL
- Name it (e.g., shootix_db3) and click Create
- Wait until Status = "available"
- Copy the "External Database URL" and "Internal Database URL"

STEP 2 - Update local .env file (use EXTERNAL URL)
----------------------------------------------------
Open: /home/user/code/photo_invoice_licence_sever/.env
Replace DATABASE_URL with the External URL (has .oregon-postgres.render.com):

  DATABASE_URL=postgresql://USER:PASS@dpg-xxxx.oregon-postgres.render.com/DBNAME
  ADMIN_SECRET=07011998
  PORT=3000


STEP 3 - Run migration to create all tables
--------------------------------------------
Open terminal in the project folder and run:

  node src/migrate.js

You should see:
  Running database migrations...
  Migration successful: all tables are ready.

STEP 4 - Update render.yaml (optional, for blueprints)
-------------------------------------------------------
Open: /home/user/code/photo_invoice_licence_sever/render.yaml
Change the database name:

  fromDatabase:
    name: YOUR_NEW_DB_NAME   <-- update this

STEP 5 - Push to GitHub
------------------------
  git add .
  git commit -m "chore: switch to new database"
  git push

STEP 6 - Update DATABASE_URL on Render (MOST IMPORTANT)
---------------------------------------------------------
** This MUST be done manually even after git push! **

1. Go to Render Dashboard
2. Open "photo-invoice-licence-sever" web service
3. Click "Environment" tab
4. Find DATABASE_URL and replace with the INTERNAL URL:
   postgresql://USER:PASS@dpg-xxxx-a/DBNAME
   (NO .oregon-postgres.render.com in this one)
5. Click "Save Changes" -> Render will auto-redeploy

STEP 7 - Verify it works
-------------------------
Run this command to confirm:

  curl -i -X GET https://photo-invoice-licence-sever.onrender.com/api/admin/licenses \
    -H "x-admin-token: 07011998"

Should return: HTTP 200 with license data.

============================================
DIFFERENCE BETWEEN INTERNAL & EXTERNAL URL:
============================================
External (use in .env on your computer):
  ...@dpg-xxxx.oregon-postgres.render.com/DBNAME  <-- has .oregon-postgres.render.com

Internal (use in Render's environment variable):
  ...@dpg-xxxx-a/DBNAME  <-- shorter, no domain suffix
============================================
